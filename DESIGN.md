# CSNIS — CS-KMITL Network & Infrastructure (`DESIGN.md`)

## Direction

- **Product**: CS-KMITL Network Infrastructure & Services portal (service catalog, network topology map, architecture inventory, and department contacts).
- **Character**: `architectural, precise, calm` — clear infrastructure documentation and live network topology.
- **Moments**: The interactive network topology map and hardware inventory table.
- **Signature**: Hairline 1px topology nodes and cards, `JetBrains Mono` IP/VLAN/port metadata, and single semantic status dots.
